# Anuwat Naukounjit

R&D Software Engineer in Bangkok. I own software products end to end -
requirements, architecture, full-stack development, on-site deployment, and
support - mostly real-time systems that talk to hardware.

Most of my work lives in private company repositories, so the contribution
graph shows activity without repository names.

## What I build

- Real-time web apps with Next.js and React, fed by device data over
  Server-Sent Events and Socket.IO
- Backend services and device-integration layers (Node.js, Express, Python,
  TCP/UDP, serial)
- Internal business systems: assignment-based permissions, state-machine
  workflows, full audit history
- Offline and cross-architecture deployments (Docker on ARM64/AMD64, native
  Windows installers)

## How I work with AI

- Claude Code is my daily tool, set up with project rule files, custom skills,
  and permission hooks for risky actions
- A personal engineering knowledge base (170+ pages) with semantic search gives
  the AI the right context
- AI-written changes are verified by tests and measurements before they ship -
  one internal app has a 306-step Playwright E2E suite
